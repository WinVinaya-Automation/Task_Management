## How to Run the Backend?

### Step 1:

- If PostgreSQL is not installed, install it with the default **port: 5432** and **password: 12345**.
- If you use a different port or password, update the relevant values in the `.env` file.
- Create a PostgreSQL database named `Tasks Management` if it doesn’t already exist.

### Step 2:

- Create a virtual environment inside the backend project directory: 
  Run the cmd in terminal ==> **python -m venv venv**

### Step 3:

- Activate the virtual environment:
  Run the cmd in terminal ==> **.\venv\Scripts\activate**

### Step 4:

- Install the required packages:
  Run the cmd in terminal ==> **pip install -r requirements.txt**

### Step 5:

- Start the backend server:
  Run the cmd in terminal ==> **python app.py**

The backend will run by default in **Port:5000**
+++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++
## How to Run the Frontend?

### Step 1:

- If Node.js is not installed, download and install it from [https://nodejs.org].

### Step 2:

- Open the terminal in the frontend project directory and install the required packages by running:
  Run the cmd in terminal ==> **npm install**

### Step 3:

- Start the frontend server:
  Run the cmd in terminal ==> **npm start**

  The frontend will run by default on **Port:3000**

Once the server is running, you can access the app in your browser.
The default path to access the Asset Management app is: **http://localhost:3000/asset-management/login**
