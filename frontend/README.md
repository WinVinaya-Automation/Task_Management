## How to Run the Frontend?

### Step 1:

- If Node.js is not installed, download and install it from [https://nodejs.org].

### Step 2:

- Open the terminal in the frontend project directory and install the required packages by running:
  Run the cmd in terminal ==> **npm install**

### Step 3:

- Start the frontend server:
  Run the cmd in terminal ==> **npm start**

  The frontend will run by default on **Port:3000**

Once the server is running, you can access the app in your browser.
The default path to access the Asset Management app is: **http://localhost:3000/asset-management/login**
